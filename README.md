# Aluguéis em Cabo Frio

Lista compartilhável de casas e apartamentos em bairros próximos ao Centro de Cabo Frio, RJ.

A página oferece filtros de preço, bairro, quartos, pets e imobiliária, ordenação, favoritos, imóveis fixados, anotações e indicação de novas adições.

## Dados e escolhas pessoais

Os anúncios e os preços são um retrato da última pesquisa, exibida na página. Taxas desconhecidas e informações pendentes ficam identificadas. Confirme disponibilidade e condições diretamente no anúncio original.

Favoritos, fixados e anotações são armazenados somente no navegador de cada pessoa. Eles não são enviados ao GitHub e não sincronizam automaticamente entre aparelhos. A página permite exportar e importar essas escolhas.

## Publicação

Site estático sem dependências, publicado pelo GitHub Pages a partir de `main`, pasta raiz. Cada alteração de `index.html` gera uma nova publicação. O arquivo `.nojekyll` mantém a publicação como HTML estático.

A busca diária e a preparação dos anúncios são executadas pela rotina local do proprietário; o GitHub Pages hospeda os arquivos publicados. Não há pesquisa automática de imóveis executada pelo GitHub.

Para corrigir uma publicação, restaure a versão anterior de `index.html` pelo histórico de commits. Não publique backups de escolhas pessoais, credenciais ou arquivos locais de controle.
